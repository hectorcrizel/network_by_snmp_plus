# Network by SNMP Plus

![Zabbix](https://img.shields.io/badge/Zabbix-7.0%2B-red.svg)
![SNMP](https://img.shields.io/badge/SNMP-Monitoring-blue.svg)

An enhanced extension of the standard Zabbix 'Network by SNMP' template, featuring advanced discovery and provider-specific tracking.

## 🚀 Key Features

*   **Cisco AP Discovery:** Custom CDP discovery specifically for Cisco Access Points.
*   **Carrier Tags:** Integrated support for provider/carrier identification on interfaces.
*   **Quality Metrics:** High-resolution packet loss tracking and jitter monitoring.
*   **Optimized Performance:** Refined polling intervals for corporate networks.

## 🛠️ Tech Stack

*   Zabbix (YAML Template)
*   SNMP (v2c/v3)
